# ArcSignal documentation

The documentation source now lives in [`content/docs`](./content/docs) and is published as a structured experience under `/docs`.

ArcSignal is experimental software on ARC Testnet. The current contracts are unaudited, market resolution is owner-controlled, winning users must call `claimWinnings`, and cancelled markets have no participant refund method in this contract version. Public developer APIs, node-operator workflows, decentralized resolution, and mainnet operation are not live features.

Start with [`content/docs/index.md`](./content/docs/index.md) or run the application and open `/docs`.
